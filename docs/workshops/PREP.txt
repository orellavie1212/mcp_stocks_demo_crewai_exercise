======================================================================
                STOCK AGENT WORKSHOP -- PRE-LECTURE PREP
======================================================================

Do these BEFORE the lecture. All four labs (1 sync, 2 async, 3 Docker, 4 GCP)
run the same commands on macOS and inside WSL2 on Windows, so the only
difference is which install track you follow below.

You do NOT need any account, API key or cloud login for prep. At the start of
the lecture you will create a Google Cloud account/project together; the
models run on Google Cloud (Vertex AI), so keep a payment card handy for that
step (the free-trial credit covers the workshop).

You do NOT need to install Python yourself: uv (installed below) downloads
Python 3.12 for you.

Total prep time: ~15 minutes depending on download speeds.

  SKIP-TO GUIDE
--------------------------------------------------------------------------------
    [Windows / WSL]   Section A
    [macOS]           Section B
    [Both OSes]       Section C -- smoke check (MUST pass before lecture)


======================================================================
  A) WINDOWS TRACK -- WSL2 + Ubuntu 24.04
======================================================================

Windows-installed tools (choco-installed terraform.exe, make.exe, Anaconda,
etc.) are Windows binaries and are NOT usable from inside WSL. Install the
linux-native versions inside Ubuntu as shown below.

--------------------------------------------------------------------------------
  A.1) Install WSL + Ubuntu 24.04
--------------------------------------------------------------------------------
Open PowerShell AS ADMINISTRATOR and run:

    wsl --install -d Ubuntu-24.04

if not working use (without version):
    wsl --install -d Ubuntu

Reboot if prompted. Launch "Ubuntu" from the Start menu and create your
linux user + password when asked.

--------------------------------------------------------------------------------
  A.2) Install Docker Desktop and enable WSL integration
--------------------------------------------------------------------------------
1. Download Docker Desktop for Windows:
       https://www.docker.com/products/docker-desktop/
2. Install and launch it.
3. Settings -> Resources -> WSL Integration -> toggle ON "Ubuntu-24.04".
4. Restart Docker Desktop once.
5. Lab 3 starts about 9 containers. Give Docker at least 6-8 GB of memory:
   on WSL2 this is set in %UserProfile%\.wslconfig ("memory=8GB" under [wsl2]),
   then run "wsl --shutdown" in PowerShell and start Docker Desktop again.

--------------------------------------------------------------------------------
  A.3) Apt installs (run inside the Ubuntu shell)
--------------------------------------------------------------------------------
Core tooling (needed for Labs 1-3):

    sudo apt update
    sudo apt install -y make dos2unix git curl gnupg

Lab 4 extras (skip if you only plan to do Labs 1-3):

    sudo apt install -y gettext-base software-properties-common wget

(gcloud is needed for ALL labs -- the models run on Vertex AI through your
Google login. It is installed in A.5.)

--------------------------------------------------------------------------------
  A.4) uv (Python package manager -- also provides Python 3.12)
--------------------------------------------------------------------------------
    curl -LsSf https://astral.sh/uv/install.sh | sh
    source "$HOME/.local/bin/env"
    uv --version

--------------------------------------------------------------------------------
  A.5) gcloud (all labs) + Terraform, kubectl (Lab 4 only)
--------------------------------------------------------------------------------
Add the Google Cloud apt repo:

    curl https://packages.cloud.google.com/apt/doc/apt-key.gpg \
      | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg

    echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] \
    https://packages.cloud.google.com/apt cloud-sdk main" \
      | sudo tee /etc/apt/sources.list.d/google-cloud-sdk.list

Install gcloud (everyone):

    sudo apt update
    sudo apt install -y google-cloud-cli

Lab 4 only -- add the HashiCorp apt repo:

    wget -O- https://apt.releases.hashicorp.com/gpg \
      | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg

    echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] \
    https://apt.releases.hashicorp.com $(lsb_release -cs) main" \
      | sudo tee /etc/apt/sources.list.d/hashicorp.list

Lab 4 only -- install Terraform + kubectl + GKE auth plugin:

    sudo apt update
    sudo apt install -y terraform kubectl \
                        google-cloud-cli-gke-gcloud-auth-plugin

Skip to Section C (smoke check).


======================================================================
  B) macOS TRACK -- Homebrew
======================================================================

Everything runs natively on macOS. The presenter's commands in the lecture
handouts are identical to what you'll run here.

--------------------------------------------------------------------------------
  B.1) Install Homebrew (skip if you already have it)
--------------------------------------------------------------------------------
    /bin/bash -c "$(curl -fsSL \
    https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

On Apple Silicon, brew installs to /opt/homebrew. The installer prints
PATH export commands at the end -- run them, or reopen your terminal.

--------------------------------------------------------------------------------
  B.2) Install Docker Desktop
--------------------------------------------------------------------------------
    brew install --cask docker

Launch Docker.app once from Applications (or Spotlight) so it finishes
setup and starts the daemon. Leave it running.

Lab 3 starts about 9 containers. Give Docker at least 6-8 GB of memory:
Docker Desktop -> Settings -> Resources -> Memory.

--------------------------------------------------------------------------------
  B.3) Install CLI tooling (all labs)
--------------------------------------------------------------------------------
    brew install make dos2unix git uv
    brew install --cask google-cloud-sdk
    uv --version
    gcloud --version

Note: macOS comes with an older BSD make. `brew install make` installs it
as `gmake`, but this workshop's Makefile works fine with either -- Apple's
default `make` is POSIX-compatible for the targets we use.

uv also provides Python 3.12, so you do not install Python separately.

--------------------------------------------------------------------------------
  B.4) Install Lab 4 tooling (skip if you only plan to do Labs 1-3)
--------------------------------------------------------------------------------
    brew install gettext terraform

Add the GKE auth plugin and kubectl via gcloud
(keeps kubectl version aligned with gcloud):

    gcloud components install kubectl gke-gcloud-auth-plugin --quiet

(Alternative: `brew install kubectl` if you prefer the brew-managed binary.
Either works for Lab 4.)

Skip to Section C (smoke check).


======================================================================
  C) SMOKE CHECK -- RUN BEFORE THE LECTURE
======================================================================

Open the terminal you'll use during the lecture:
    [Windows / WSL]  Ubuntu from the Start menu
    [macOS]          Terminal.app or iTerm

Paste this block and confirm every line prints a version (no "not found"):

    make --version
    git --version
    uv --version
    uv python install 3.12
    uv run --python 3.12 python --version
    docker version
    docker compose version
    terraform -version
    gcloud --version
    kubectl version --client

(gcloud must work for everyone. If you only plan to do Labs 1-3, terraform
and kubectl may be "not found" -- that is fine.)

Expected highlights:
  - uv run ... python --version -> Python 3.12.x (this downloads Python the
                          first time; 3.13 is NOT supported by the workshop)
  - docker version     -> prints both Client AND Server sections
                          (if Server is missing, Docker Desktop isn't
                          running or WSL integration isn't enabled)
  - docker compose version -> v2.x
  - terraform -version -> 1.6+ is fine
  - gcloud --version   -> any recent version
